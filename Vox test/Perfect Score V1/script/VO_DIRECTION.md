# Voice direction for a human re-record

The narration in *Perfect Score V1* is synthetic. It is a new voice blended from two stock male
styles of an open text-to-speech model, so it does not clone any real person. To replace it with a
real narrator, record the script below. Then run `src/mix.py` with the new file in place of
`vo_raw.wav`. Everything else (score, SFX and picture) is timed to the start times listed here.

## Voice and recording
* **Voice:** male, low-mid (around 120–135 Hz speaking pitch), warm and close. A storyteller, not an announcer.
* **Pace:** about 3.4 words per second, quick but clear. Pauses only where marked.
* **Setup:** a large-diaphragm condenser or SM7B-type dynamic, 10–15 cm away, pop filter, treated room or closet.
* **Format:** 48 kHz / 24-bit WAV, peaks around −10 dBFS, no processing. The mixer adds EQ, de-essing, compression and room.
* **Timing:** record each line separately or in one take. Line starts must match the times below within ±0.1 s.
