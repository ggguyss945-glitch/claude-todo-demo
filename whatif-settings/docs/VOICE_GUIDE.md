# Voice guide for Fish Audio — "What If Real Life Had a SETTINGS MENU?"

Pick **one voice per role** (official voices or ones you designed — no clones of real people or cartoon characters),
on a plan that allows commercial use. Send me the **4 test lines** first (one per main role, below) so I can check them.

| Role | Voice to look for | Notes |
|---|---|---|
| N — Narrator | Young adult male storyteller, energetic, clear | Two registers: **excited** (HYPE lines) and **calm/flat** (DEADPAN lines). The deadpan is the joke — don't oversell it. |
| SYS — Settings voice | Calm, clean, friendly female (or neutral) assistant | Always polite and cheerful, even when the world is ending. I add the chime and the "digital" filter. |
| SAM — the kid, 12 | Real boy voice, 11–13 | Natural, quick, expressive. |
| LILY — little sister, 6 | Real girl voice, 6–8 | Her "I WANT THE BLUE SPOON!" must be as loud and shrill as possible. The last line is a tiny whisper. |
| MOM | Bright, warm, firm woman | "SAM! UP! NOW!" is a big yell (Day 1 and Day 7 use the same file). |
| DAD | Deadpan baritone | Flips to falsetto panic on "BLESS MEEEEE!". Pirate and robot lines in character. |
| PICKLES — the cat | Deep, slow, posh, bored man | Bored aristocrat. Never excited. |
| BRIGGS — teacher | Older man, monotone | Read his fast line at **normal speed** — I speed it up to chipmunk. |
| KEVIN — neighbour | Smug, slightly nasal man | |

**Lines I process, so read them normally:** S03 Briggs's fast line (I speed it up), Sam's "Noooooo..." on Day 3 (I slow it down),
SYS "Fooorty... fiiive..." on Day 7 (I slow it down), Dad's robot "DUCK. BREAD." (I add the robot effect), SYS lines (I add the filter).

**Test lines (send these first):** `S00-L001_N`, `S00-L005_SYS`, `S00-L006_SAM`, `S01-L011_LILY`.

**Files:** WAV (or MP3 at 192 kbps+), no music, no effects, no speed-up.
Either one file per line named `<ID>_<ROLE>.wav` (e.g. `S00-L006_SAM.wav`), or one file per role per scene with ~1 s of silence
between lines named `<scene>_<ROLE>.wav` (e.g. `S01_DAD.wav`) — I split them. Zip per role or per scene; up to 5 files per chat message.
I check every line automatically (clipping, loudness, words against the script) and send you a short retake list if needed.
